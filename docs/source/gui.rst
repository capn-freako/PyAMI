pyibisami.gui
=============

Qt (PySide6) widgets and dialogs for the *PyIBIS-AMI* model classes, and the ``pyibisami-gui`` viewer.
Requires the ``gui`` extra: ``pip install 'pyibis-ami[gui]'``.

The widgets are plain ``QWidget`` s, so applications can embed them.
Each one follows its core object live, including changes made on other threads (see ``bridge``).
